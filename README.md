# 💍 Margarida & Gonçalo

Se não te enviei este link, é porque não estás convidado. Não aceitamos penetras no casamento — nem no repositório.

Se chegaste até aqui a bisbilhotar o código-fonte em vez de responder ao convite... primeiro, confirma presença. Depois falamos de CSS.

## O que é isto

O site do nosso casamento (03 · 07 · 2027). Tem contagem decrescente, a nossa história, onde é o copo-d'água e um botão para confirmares presença — de preferência pessoalmente, com direito a abraço, mas em último caso aceitamos WhatsApp.

Também tem um convite em forma de envelope que se abre a tocar, porque um simples "estás convidado" no WhatsApp não tinha o mesmo efeito.

## Estrutura

```
index.html       → site principal
invite/          → convite (o envelope)
styles.css       → estilos do site principal
invite.css       → estilos do convite
images/          → fotos (já otimizadas, não voltes a meter uma de 6MB direta da câmara)
```

## Correr localmente

```
python3 -m http.server 8011
```

Abre em `http://localhost:8011`.

## Regras da casa

- Se és um programador a curioso a espreitar isto: os cantos arredondados no Safari deram luta, não perguntes.
